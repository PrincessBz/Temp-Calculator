# 🎬 Movie Theatre Seat Reservation System

This is a Java console-based application that simulates a movie theatre seating system. Users can reserve or cancel seats and view the current seating chart.

## 🚀 Features

- ✅ Reserve a seat (notifies if seat is already taken)
- ❌ Cancel a reservation
- 🪑 View current seating chart (shows reserved and available seats)
- 💾 Uses `ArrayList` to manage seat objects

## 🧱 Tech Stack

- Java (JDK 8+)
- IntelliJ IDEA or any Java IDE
- No external libraries
